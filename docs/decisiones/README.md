# Decisiones de diseño

Registro breve (estilo ADR) de las decisiones que no se deducen del código: qué se decidió y por
qué. Un archivo por área; cada decisión, unas líneas. Si cambias una, actualiza su entrada (o
márcala como sustituida) en el mismo commit.
